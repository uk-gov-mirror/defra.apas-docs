# Next steps

You can use the results from the tool to inform your air pollution assessment report for submission to the planning authority or regulator, or to an ecological specialist for interpretation.

You should also use the report export option to export a file which will contain all of your model settings and results. This file should be shared with the planning authority or regulator alongside your standard air pollution assessment report.
